# Workflow：Seedream 5 + Seedance 2.5 —— 先生图后生视频

> 核心主张：**用便宜的图像生成把"角色/场景/商品/风格"全部定死成一套统一参考，再一次性喂给 Seedance 2.5 生成 30 秒视频。** 抽卡一次过，省钱又可控。
> 配套提示词：本仓库 [中文提示词示例库（100 条 30 秒分镜）](../i18n/README_zh.md)。

---

## 省钱到底省在哪（先说清楚，别自欺）

"先图后视频"本身**不是**省钱魔法——它早就是行业标配，"图比视频便宜"更是同义反复。真实成本是：

```
一条成品成本 ≈ 单次生成价 × 出成品前的抽卡次数 + 衍生条数
```

昂贵的是**视频抽卡次数**和**4K/30s 终版**。所以真正的省钱杠杆是 **"少抽贵的、只抽准的"**，靠三招：

1. **验证闸门阶梯**：纸面分镜 → 一张网格图（几毛）→ 低清短样验运镜 → 4K/30s 终版**只抽 1 次**。每道闸都便宜，昂贵抽卡几乎不浪费。
2. **锁死关键帧 → 视频首次成功率拉满**。这才是"先图"真正省钱的机制：把画面/一致性在图上确认后，视频模型几乎无需自行发挥，**重抽次数骤降**——而不是因为"图便宜"。
3. **频道/系列 DNA 母版 + 编辑衍生**：每条只换增量，不从零重建。

顺带：**一张画布网格出图**（见下）把 N 次图像生成压成 1 次，图省了、时间省了，还附赠强一致性。

| 维度 | 直接抽视频 | 先图后视频（本工作流） |
|---|---|---|
| 抽卡次数 | 靠文字赌，反复重抽 | 关键帧锁死，首次成功率高，重抽少 |
| 昂贵终版 | 每次试错都可能烧 4K | 低清验证通过后，4K 终版只抽一次 |
| 一致性 | 角色/商品靠模型脑补 | 参考图锁死，跨镜稳定 |
| 衍生 | 每条从零抽 | 母版 + 编辑，只付增量 |

## 能力对齐（本工作流用到的两个模型）

**Seedream 5.0 / 5.0 Pro（图像）**【已确认】
- 文本 + 多图输入，支持多图融合、图像编辑、组图生成。
- 参考图最多 14 张；参考图数量 + 生成数量 ≤ 15。
- 尺寸 1K/2K/3K/4K。
- 5.0-lite 支持深度思考 + 联网搜索（可融合实时信息，如天气/商品）。
- prompt 建议 ≤300 汉字 / 600 英文词。

**Seedance 2.5（视频）**【已确认】
- 30 秒单次一镜连贯生成（非拼接）。
- 最多 50 份全模态参考（图/视频/文字）。
- 原生 4K / 10bit；支持局部编辑（换背景/商品/模特）。

> 衔接点：Seedream 输出的正是 Seedance 需要的"多参考素材"。两者同源（字节 Seed），风格链路一致，衔接损耗小。

## 五步工作流

```
① 定方案 → ② 生成参考资产(Seedream 5) → ③ 组多参考调用 → ④ 生成视频(Seedance 2.5) → ⑤ 精修交付
```

### ① 定方案（纸面，0 成本）
先写清楚：时长、比例、风格总纲、要讲的一件事、4–6 段分镜大纲。
产出：一份"拍摄脚本"（就是 01 教程里的四层结构骨架，先不填素材）。

### ② 用 Seedream 5 生成全部参考资产（便宜）

> **优先"一张画布网格"出图**：别把角色/场景/道具一张张分开抽。像画漫画分镜一样，**一次生成一整张 N×M 网格图**（每格一个镜头关键帧或一类参考），同一次绘制天然一致，还把 5–6 次图像生成压成 1 次。生成后用脚本切帧：
> ```
> python skills/consistent-character-video/scripts/split_grid.py grid.png --rows 2 --cols 3 --out frames/
> ```
> 分镜网格图（一张画布出 N 帧）是这套流程的关键技巧：一次生成、跨镜一致，再切割成单帧作参考图。
>
> 单画布不适用时（如需要单独反复调某个角色的脸），再退回下面的"按功能角色分别出图"。

按官方"四种功能角色"精配素材（不堆满）：角色锚定 / 场景定调 / 运镜参考 / 节奏氛围。

- **角色定妆（关键·按官方来）**：给每个关键角色生成**一张独立大头照（仅头部、无表情最佳、去背景干扰）+ 一张全身妆造照**。
  > 🚫 **不要生成"正/侧/背多视图"**——官方明确多视图会被模型识别成多个主体，加剧 ID 漂移与双胞胎。
  > Seedream 提示例：`一位25岁女性，黑色长发，干净纯色背景，头部特写大头照，无表情，五官清晰` + 另生成 `同一位女性，米色风衣全身站姿，棚拍柔光，写实`。
- **场景板**：关键场景各出 1 张，统一光照和色调。
- **商品图**：正面图 + 材质细节 + 结构图（电商/工业必备）。
- **风格板**：一张"整体调性参考"统一全片色彩。
- **首帧图**：为最关键的镜头（尤其开场）生成理想首帧——视频阶段"让它动起来"成功率最高。

> 省钱要点：Seedream 一次可生成组图，低分辨率(1K/2K)先选，选中的再出 4K。参考图上限 14 张，优先把额度给"关键角色的大头照+全身"。

### ③ 组多参考调用（用官方 `主体@图片N` 语法）
把选定的图按上传顺序编号，写进提示词时用官方语法绑定（见 01 教程第二部分）：
```
参考图片1中的主播（面部参考图片1大头照，妆造参考图片2全身照）为主播，
参考图片3的展台为场景，参考图片4的商品为商品，参考图片5的调性为风格……
```
能用图表达的空间关系优先用图，减少复杂文字；**越需要精准的素材放越靠前**（重要素材前置）。

### ④ Seedance 2.5 生成视频
把多参考 + `镜头1/2/3` 分镜 + 音频符号 + 约束词拼成完整 prompt（模板见 01 实战示例、02 画廊）。
- 首版用 **1080p + 较少镜头** 跑通分镜/运镜逻辑，确认无漂移。
- 通过后再出 **30 秒 4K 终版**。
- 满意版**锁定 seed**，后续只做局部微调。

## 四条典型工作流实例

### 实例 A：电商带货 30 秒（最高频）
1. Seedream 出：模特大头照+全身各 1 张 + 白色展台场景 1 张 + 商品正面/材质 2 张 + 风格板 1 张。
2. 多参考调用 → Seedance 出 1080p 打样确认动作/运镜。
3. 4K 终版 → Seed-Audio 配女声口播 + 轻电子 BGM。
4. 用**编辑视频任务**（`严格编辑视频1，将口红颜色改为图片X`）批量换色号/换背景 → 一次投入出十几条 SKU 素材。
> 省钱账：模特+场景+商品图 ~6 张（几块钱）→ 视频抽 1 条母版 → 衍生 N 条编辑任务。对比每条从零抽，成本降一个量级。

### 实例 B：系列 IP 短视频（一致性优先）
1. Seedream 固化 IP 角色的**大头照（无表情）+ 全身妆造照**，存为资产库（**不做多视图**）。
2. 每集复用同一套角色参考图 + `面部参考图片1，妆造参考图片2` 绑定 → Seedance 保证跨集不崩。
3. 只换场景板和分镜，角色参考不变。
> 价值：解决"AI 做系列内容角色会变"的头号痛点。官方明确多视图会加剧漂移，故用大头照+全身。

### 实例 C：科普/解说协同（官方同款打法）
1. Seedream（可开联网搜索）生成准确的主体渲染图/示意图（探测器、器官、机械结构等）。
2. 多参考调用 → Seedance 出 30 秒连贯解说画面，解说词用 `{}` 台词符号写进提示词。
3. Seed-Audio 配解说旁白（或直接用 Seedance 原生音频）。
> 官方演示即用 Seedream 5.0 Pro + Seedance 2.5 做"天问一号"科普片。

### 实例 D：动画厨房做饭视频（TikTok 食欲向 · 完整案例）
只拍手+食物、吉卜力食物番风、可复制频道模板。用**一张画布网格**出 6 格分镜关键帧 → 切帧 → Seedance 一次直出 30s 多镜头，ASMR + money shot 拉满。
> 每一步都可套用上文的"验证闸门阶梯"，配合本仓库中文示例库里的餐饮/美食分镜脚本直接复制使用。

## 省钱清单（贴在墙上版）

1. **验证闸门阶梯**：纸面 → 网格图（几毛）→ 低清短样 → 4K 终版只抽一次。
2. **锁死关键帧拉满首次成功率**——"先图"省钱靠的是少重抽，不是"图便宜"。
3. **一张画布网格出图**，把 N 次图像生成压成 1 次。
4. **参考图精配且高质量**——官方不建议堆满，关键角色大头照+全身备到位即可。
5. **母版 + 编辑视频任务批量衍生**，别每条从零抽。
6. **锁 seed 微调**，别每次全新抽卡。
7. **预算集中在前 2 秒和关键帧**，不均摊浪费。
8. **同源链路**（Seedream→Seedance→Seed-Audio）减少风格返工。

## 常见衔接问题

| 问题 | 解法 |
|---|---|
| Seedream 出的图和视频风格对不上 | 用同一张"风格板"贯穿图和视频两端；两模型同源，尽量别中途换第三方图模型 |
| 参考图给太多反而乱 | 官方不建议堆满；精配四功能角色；相似元素别重复喂 |
| 视频里角色比图里"变样" | 用独立大头照（无表情）+ 全身照，勿多视图勿混图；prompt 写"面部参考图片N"；重要素材前置 |
| 30 秒中段风格漂移 | 明确风格约束词 + 角色/场景锁；或先把参考图转成目标风格再生视频 |
| 4K 终版太贵想省 | 1080p 出母版 + 后期超分；仅对最终交付版出原生 4K |
